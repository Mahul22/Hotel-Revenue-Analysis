This Power BI project focuses on analyzing the revenue of a hotel dataset. The project involves importing and transforming hotel booking data, such as room types, booking dates, rates, occupancy, and customer details. Using Power BI's interactive visualizations, the analysis includes revenue trends over time, room category performance, seasonal fluctuations, and key metrics like average daily rate (ADR) and revenue per available room (RevPAR). The dashboard enables stakeholders to monitor overall hotel performance, identify peak periods, and optimize pricing strategies to maximize revenue. Insights can also be derived on customer demographics, booking channels, and location-based performance.
